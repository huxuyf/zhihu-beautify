# 知乎美化

提高知乎使用体验的油猴脚本（UserScript）。

- **作者**：ShingU
- **版本**：0.9.21
- **许可证**：MIT

## 功能

### 阅读体验
- **默认收起回答**：回答默认折叠，只保留标题与摘要，按需展开
- **一键收起回答 + 评论**：右下角悬浮按钮，一键收起页面内全部回答与评论
- **收起当前回答 / 评论**：点击页面两侧空白处，收起当前浏览的回答
- **快捷返回顶部**：右键点击页面两侧空白处，立即回到顶部
- **移除高亮链接**：去掉 zhida.zhihu.com 的站内搜索高亮跳转

### 信息增强
- **区分问题 / 文章 / 想法**：内容标题前显示彩色类型标签
- **直达问题按钮**：回答卡片上显示「直达问题」按钮
- **完整显示时间**：展示「发布于 / 编辑于」的完整时间
- **置顶显示时间**：把发布时间置顶到卡片头部
- **问题创建时间**：展示问题的创建时间与最后编辑时间
- **显示问题作者**：问题页展示问题作者信息

### 图片与链接
- **默认高清原图（无水印）**
- **默认站外直链**：站外链接直接跳转目标站，绕过 link.zhihu.com 跳转页

### 剪贴板消毒
- 复制时清理零宽字符，自动去掉尾部的「阅读全文」「赞同 / 评论」按钮文案、发布时间、IP 属地等附加信息，只保留纯正文

### 页面布局
- **隐藏右侧栏**：主内容占满整行
- **首页双栏阅读**：推荐流 50/50 双栏 + 右侧正文预览面板，点击卡片即可预览
- **推荐流赞同数过滤**：只展示赞同数 ≥ 10 的内容
- **页头导航精简**：隐藏关注 / 热榜 / 专栏 / 圈子 / AI Works / 故事 / 推荐等导航入口
- **隐藏编辑区**：隐藏「写回答 / 写想法」编辑区

## 安装

1. 安装用户脚本管理器：Tampermonkey 或 Violentmonkey
2. 新建脚本，将 [`知乎美化-0.9.21.txt`](./知乎美化-0.9.21.txt) 的全部内容粘贴保存

> 脚本自动匹配 `www.zhihu.com` 与 `zhuanlan.zhihu.com` 下所有页面。

## 兼容性

| 管理器 | 说明 |
| --- | --- |
| Tampermonkey | 支持；4.18+ 版本会自动延迟启动以等待页面加载 |
| Violentmonkey | 支持；加载时机更早，脚本会延迟执行 |
